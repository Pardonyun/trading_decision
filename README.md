# 已知价格单日事前决策样例

运行 Python 3.11+，并确保 `zoneinfo` 能找到 IANA 时区数据；Windows 环境通常需要安装 `tzdata`：

```powershell
python -m pip install -r requirements.txt
python -m trading_decision examples/known_prices.json
```

`examples/known_prices.json` 是**合成的已知价格**，用于验证流程，不代表 CAISO SP15 真实报价。运行日为 2026-11-11，平台北京时间截止时刻为 02:00（UTC 2026-11-10 18:00）。D−7 的 24 个价格于截止前发布；目标日实际价格于截止后发布。样例将数组第 1 至 24 项分别对应平台第 1 至 24 时段，并给出每个时段的市场本地起点和 UTC 偏移。程序按 `America/Los_Angeles` 核对偏移，不接受把夏令时日期写成全年固定的 −08:00。

入口先调用 `freeze_decision`：只取截止前可见的 D−7 同时段价格，生成 24 个预测价，再以当天起始 SOC 求解 24 个有符号功率值。储能优化器在配置的提交小数精度上最大化预测价格下的当日交易收益，约束为 14 MWh 容量、5%–95% SOC、±7 MW 功率、充放电各 85% 效率和同小时互斥；日末 SOC 不固定。相同收益时优先全零或更少充放电量。独立校验器复算最终 24 个功率值、每小时及第 24 小时结束后的 SOC。求解失败、超时、无解或候选校验失败时，记录状态和原因，重新验算并冻结 24 小时全零计划。

`settle_day` 只在计划冻结后接收目标日实际价格，用已冻结功率结算储能日收益，并把第 24 小时后的 SOC 作为次日起始 SOC。输出还记录求解状态、预测收益、保底原因、逐时 SOC、运行日、北京时间截止时刻、UTC 可见边界、价格发布时间和截止后被忽略的历史记录数。改变结算价格不会改变已冻结的优化结果。

本例从 5% SOC 起步，预测曲线逐时上涨，因此会先充电、后放电；用样例实际价格结算的储能日收益为正。价格和功率均按平台时段顺序输出。提交功率精度尚待核实，当前默认保留最多 4 位小数，可用 `--power-decimal-places` 修改；这只是本地提交格式假设。缺失或重复时段、非连续市场小时、无时区时间戳以及越界计划会报错，不会静默补齐。加州夏令时切换日的 23/25 市场小时与比赛固定 24 时段的映射尚未确认，因此此入口只接受明确连续的 24 小时样例。截止时刻以输入中的平台北京时间为准，可落在运行日前一天。
