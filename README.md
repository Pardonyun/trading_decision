# 已知价格单日事前决策样例

本项目的比赛工作流是：人工更新已公布的真实电价 CSV，再预测下一运行日的 24 个价格，最后根据预测电价和起始 SOC 生成储能自调度曲线。程序不主动获取电价。内部按“运行日 + 平台时段 1–24”匹配价格与功率，不要求时间戳或时区转换。导入真实 CSV 时须确认每个运行日的 24 个平台时段与比赛提交顺序一致；实际列名和格式等收到 CSV 样本后适配。

当前可运行入口是一个**合成的已知价格 JSON 样例**，用于验证 D−7 同时段价格基线、优化、计划校验和结算流程，不代表真实 CAISO SP15 报价，也不是最终预测模型。运行 Python 3.11+：

```powershell
python -m pip install -r requirements.txt
python -m trading_decision examples/known_prices.json
```

样例以运行日 D−7 的 24 个价格作为 D 日预测价，再以 D 日起始 SOC 求解 24 个有符号功率值。储能优化器在配置的提交小数精度上最大化预测价格下的当日交易收益，约束为 14 MWh 容量、5%–95% SOC、±7 MW 功率、充放电各 85% 效率和同小时互斥；日末 SOC 不固定。相同收益时优先全零或更少充放电量。独立校验器复算所有时段及第 24 小时结束后的 SOC。求解失败、超时、无解或候选校验失败时，记录状态和原因，并冻结重新验算过的 24 小时全零计划。

`freeze_decision` 只接收历史价格，先冻结预测和计划；`settle_day` 再接收目标日实际价格，用已冻结功率结算储能日收益，并把日末 SOC 作为次日起始 SOC。改变结算价格不会改变已冻结的计划。手工更新的 CSV 是当次决策可用数据的边界；若要准确重放过去的决策，应保存当时的 CSV 快照，避免后来补录或修订的数据进入过去的预测。

样例从 5% SOC 起步，预测曲线逐时上涨，因此先充电、后放电。价格和功率均按平台时段顺序输出。提交功率精度尚待核实，当前默认保留最多 4 位小数，可用 `--power-decimal-places` 修改。缺失、重复时段或越界计划会报错，不会静默补齐。

运行测试：

```powershell
python -m unittest discover -s tests -v
```
